## Findings found by the end-to-end run

The simulator and phone-UI harness (`scripts/e2e/`, merged in b658c35) found and fixed three defects that unit tests missed:
- CORS did not allow the `Idempotency-Key` header, so browser retries failed (c2a8b6d).
- A stalled token read caused spurious 401s that logged the coach out (b2810b4).
- Only a freshly read token's 401 now triggers re-pairing (868993e).

Run safety: 0 emails sent, 0 non-loopback fetches, 0 unscripted model calls. Scenarios are synthetic and use a scripted fake model, so prompt quality and real STT are not exercised.

### Documented limits found in the e2e run

- The quiet peek `2×: end` hint only shows when there is no "Next to note" line.
- The "Nothing changed" hint is not on the first card page.
- The simulator console flood is handled in the harness, not in the product.
