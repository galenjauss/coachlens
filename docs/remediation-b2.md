## Shape notes for the controller

- The C2 and C3 request and response shapes come from the shared schemas added by batch 3 (`UndoResponse`, `NoteCandidates`, `StudentCreate`, `StudentUpdate`, `ClassCreate`, `ClassUpdate`). No shared schema was changed.
- The server is stricter than the shared schemas in a few places: aliases must look like names, rankSince must be a real date, and a student patch must not be empty.
- The Undo reply also carries `coverage`, which the client's `UndoReply` already accepts.
- One existing test expectation changed: `POST /v1/diffs/<unknown>/accept` now gets 404 instead of 409, because ownership is checked first.
