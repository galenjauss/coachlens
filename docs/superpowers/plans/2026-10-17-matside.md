# MatSide Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build MatSide: an Even Hub app for G2 where a solo kids' martial arts instructor runs an AI-drafted drill deck on the lens and speaks notes that start autonomous agent workflows. Includes a phone UI inside the Even app and a hidden backend.

**Architecture:** npm workspaces monorepo.
- `shared/`: Zod contracts used by both sides.
- `api/`: Hono on Vercel Functions, Drizzle + Postgres (Neon in prod, PGlite in tests), agents on AI SDK 7 via AI Gateway, OpenAI transcription, Resend email, Vercel Cron.
- `app/`: the Even Hub app (Vite + TS). Contains a pure lens state machine + renderer driving SDK containers, React phone screens, and an outbox that survives offline/lock.

**Tech Stack:** TypeScript 5, Node 24, Vite 5, React 19, Hono 4.13, drizzle-orm 0.45 / drizzle-kit 0.31, @neondatabase/serverless 1.2, @electric-sql/pglite (tests), ai 7 (AI Gateway model strings), openai 7, resend 6, zod 4, vitest 5, @evenrealities/even_hub_sdk 0.0.16, @evenrealities/evenhub-cli 0.1.14.

**Spec:** [docs/superpowers/specs/2026-10-17-matside-design.md](../specs/2026-10-17-matside-design.md)

## Global Constraints

- **Deadline:** Sun 2026-10-18 12:00 PM PT. Devpost + Even Hub **Beta** build.
- **App name:** `MatSide` (≤20 chars, must not contain "Even"). package_id `com.matside.app`.
- **SDK + manifest:**
  - `@evenrealities/even_hub_sdk` 0.0.16. `app.json` `min_sdk_version: "0.0.16"`, `edition: "202601"`.
  - Permissions: `g2-microphone`, `network` (whitelist = exact API origin, no wildcards).
- **Lens:** canvas 576×288, monochrome. ≤8 text/list containers per page (≤12 total), exactly 1 with `isEventCapture: 1`. List ≤20 items × ≤64 chars. `containerName` ≤16 chars. No font size control.
- **Events:**
  - CLICK arrives as `eventType` `undefined`, so normalize **inside** the envelope check.
  - Long-press and its release arrive on `sysEvent`.
  - Double-tap on the root (home) screen must call `bridge.shutDownPageContainer(1)`.
- **Bridge + first run:** always `await waitForEvenAppBridge()` before SDK calls. First run shows instructions on the glasses ("never a black screen").
- **Audio:** PCM 16 kHz, s16le, mono via `bridge.audioControl(true, AudioInputSource.Glasses)`. Re-arm on resume.
- **Secrets:** no API keys in the app. All secrets in Vercel env only.
- **Network:** API must send CORS headers. Whitelist ≠ CORS bypass.
- **Billing:** flags/notes only. **No payment code anywhere.** No medical diagnosis; injuries are logged as observations.
- **Autonomy tiers:** parent emails and report cards always `pending_review` until approved. All sends go to `DEMO_EMAIL_OVERRIDE` when it is set.
- **Model:** `anthropic/claude-sonnet-5-5` via AI Gateway (`generateText` + `Output.object`, `instructions` not `system`).
- **Skill tag taxonomy (fixed):** `stance, guard, kicks, strikes, forms, footwork, focus, effort, respect, sparring`.
- **Thresholds:**
  - Name match: auto ≥ 0.88, ambiguous ≥ 0.75, else unassigned.
  - Recurring issue: same tag ≥ 3 times in 30 days with no open issue.
- **Latency target:** `/utterance` ≤ 3 s to the agent card. Parent email + planner run after the response via `defer`.
- **Commits:** conventional commits (`feat:`, `fix:`, `test:`, `chore:`, `docs:`). Each commit ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Demo platform:** iPhone (iOS keeps the WebView alive while locked).
